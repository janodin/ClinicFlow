Setup Instructions

Follow these steps to activate Messenger booking via n8n.

  1. 1 Go to your Meta Developer Dashboard and get your Page ID and Page Access Token.
  2. 2 Enter the Page ID, Access Token, and a Webhook Secret above, then click Save Settings.
  3. 3 In n8n, create a Facebook Messenger workflow using the Django Webhook URL above as the target for the HTTP Request node. Include the webhook secret in the X-N8N-Webhook-Secret header.
  4. 4 Patients can now message your Facebook Page to book appointments. The bot will guide them through service selection, date, time, and confirmation.
